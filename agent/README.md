# Agent 沉淀与交付目录

此目录专门由 Agent 维护，用于八股复习中的机器生成物与周期性复盘：

- `merges/`：多分支或深度讨论的完整归档文件
- `drills/`：全真模拟面试记录与打分复盘
- `cheat-sheets/`：高频对比图表与公式速查卡

开始工作前阅读根目录 [AGENTS.md](../AGENTS.md)。标准答案先检索[知识库](../knowledge-base/README.md)并读取原文依据；面试实录保存证据，[薄弱点台账](../WEAK_POINTS.md)维护当前状态，[错题集](../knowledge-base/mistakes/README.md)保存纠偏与复习历史。
