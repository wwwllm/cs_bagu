# 八股知识库与薄弱点闭环追踪系统

本项目旨在记录与沉淀计算机核心八股的底层深度解析、面试拷打记录以及个人薄弱点跟踪。

## 一、 核心模块结构

- `01-computer-network/`：计算机网络（自顶向下模型，应用层/传输层/网络层/链路层深度八股）
- `02-computer-system/`：计算机系统（CSAPP、Linux 操作系统、虚拟内存、进程/线程、IO多路复用）
- `03-database/`：数据库（MySQL InnoDB、索引原理、MVCC、锁机制、Redis 核心与缓存设计）
- `04-data-structures/`：数据结构与算法八股（红黑树、B/B+树、跳表、LRU/LFU、布隆过滤器等）
- `agent/`：Agent 专属工作沉淀区（分支会话合并、面试实录与打分、高频对比速查卡）
- `WEAK_POINTS.md`：**全局薄弱点跟踪台账**（按 🔴/🟡/🟢 状态机流转）

## 二、 薄弱点状态流转规范

| 标记 | 状态 | 判定标准 | 流转动作 |
| :---: | :---: | :--- | :--- |
| 🔴 | **Need-Review** | 概念混淆、无法推导、连环追问卡壳 | 记入待办，下一次模拟面试优先抽查 |
| 🟡 | **Improving** | 主线逻辑正确，但缺底层实现细节或工业级度量 | 加深底层机制理解，再抽查一次 |
| 🟢 | **Mastered** | 对答如流，能抗住 2 轮以上连环追问并答出底层实现 | 移入已掌握归档，周期性回抽验证 |

## 三、 使用流程

1. **面试拷打**：在 Agent 对话中按单题深入回答八股。
2. **知识沉淀**：讨论结束后由 Agent 提取核心原理，更新对应模块笔记与 `agent/`。
3. **薄弱点入账**：暴露出的问题与盲区自动登记到 `WEAK_POINTS.md`。
4. **二刷抽查**：指定从 `WEAK_POINTS.md` 中抽题复盘，直至全部翻绿（🟢）。
